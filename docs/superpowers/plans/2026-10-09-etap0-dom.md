# Etap 0 „Dom” – plan implementacji

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bot Telegram „Dom” na n8n (Mac) plus prompty Claude, które razem realizują Etap 0: dodawanie spraw do wspólnego kalendarza, przyciski, kolizje, 🎰 Los, 🔥 Combo, 🙌 Piątka, cele tygodniowe, brief poranny i podsumowanie tygodnia.

**Architecture:** Cała logika bota to czyste moduły JS w `src/` z wstrzykiwanym `io` (Telegram, Gemini, Kalendarz, sleep), testowane `node:test` na atrapach. `scripts/build-workflows.mjs` pakuje je esbuildem w jeden skrypt i generuje workflow n8n: wyzwalacz co 5 s i jeden węzeł Code, który wywołuje `DomBot.main(...)`. Planowanie i rachunki robią Routines Claude według promptów z `prompts/`.

**Tech Stack:** Node.js ≥ 20 (ES modules, `node:test`), esbuild 0.23.1 i ajv 8.17.1 (tylko dev), n8n (Docker na Macu), Telegram Bot API, Gemini API (REST `generateContent`), Google Calendar API v3 (REST, OAuth refresh token), GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-09-etap0-dom-design.md`

## Global Constraints

- Brak zależności runtime; dev: tylko `esbuild@0.23.1`, `ajv@8.17.1`. `"type": "module"`, Node ≥ 20.
- `npm test` = `TZ=UTC node --test`; kod nigdy nie zależy od strefy maszyny, zawsze `Europe/London` z konfiguracji.
- Znaczniki: osoby 🟦 (b), 🟩 (g), 🟨 (y, razem); typy 💸 rachunek, 🧩 krok, 📥 nieposortowane; zrobione: `✅ ` na początku tytułu.
- Tytuł: `[✅ ]<osoba> [<typ> ]<treść>`. Klucze opisu dokładnie: `utworzone_przez`, `źródło`, `kwota`, `termin`, `zrobione`, `pkt`, `combo`.
- Potwierdzenie dodania: `<osoba> <treść> · <dzień> <dd.mm>, <HH:MM>`, np. `🟦 Dentysta · pt 16.10, 18:00`; przyciski `✅ Zrobione`, `⏰ +15 min`, `Jutro`, `↩️ Cofnij`.
- Pytanie o dzień: `Dziś`, `Jutro`, `Weekend`, `Przyszły tydzień`. O porę: `Rano 9:00`, `Po południu 15:00`, `Wieczór 19:00`, `Cały dzień`.
- Kolizja: `⚠️ koliduje z <tytuł>` + `Wstaw o HH:MM` (najbliższe wolne co 30 min w ciągu 3 h) + `Zostaw`.
- Punkty: bazowy 1 dla klikającego (🟨: obu); 🎰 bonus 777 +9, inna trójka +4, para +1, brak 0; combo okno ≤ 20 min, max x5, bonus = poziom − 1; piątka gdy ✅ ≤ 60 min po ostatnim ✅ drugiej osoby, przerwa 60 min, +2 dla obu. Bonusy 🎰 i 🔥 tylko dla klikającego.
- Cel tygodnia = `max(5, ceil(0.9 × średnia z 2 ostatnich pełnych tygodni))`; przy mniej niż 2 tygodniach historii 5. Tydzień pn 00:00 – nd 23:59 Europe/London. Paski: 5 bloków `▓`/`░`, bloki = `round(% / 20)`.
- Bot nie usuwa wydarzeń poza `↩️ Cofnij` na własnych (`utworzone_przez: bot`) młodszych niż 24 h. Routines nie usuwają nigdy.
- Gemini wypełnia tylko pola schematu; akcje decyduje kod. Limit `GEMINI_DAILY_LIMIT` (domyślnie 200) dziennie.
- Żadnych sekretów ani danych osobowych w repo; skaner sekretów w testach i CI.
- Teksty bota po polsku, bez form zależnych od płci.

**Doprecyzowania specyfikacji** (do potwierdzenia przez użytkownika przy przeglądzie planu):
1. ID Telegrama i e-maile osób w `n8n/.env` (zmienne `TELEGRAM_ID_NIEBIESKI`, `TELEGRAM_ID_ZIELONY`, `EMAIL_NIEBIESKI`, `EMAIL_ZIELONY`) zamiast `config/osoby.json`, bo węzeł Code czyta zmienne środowiska, a nie pliki.
2. `pkt` zapisuje punkty per osoba: `pkt: 🟦3 🟩1` (spec miał `pkt: 3`), bo 🟨 i piątka dają punkty obu osobom. Nowy klucz `combo: x3` zapisywany, gdy poziom > 1 (potrzebny do „najdłuższego combo” w podsumowaniu).
3. Przypomnienia: wydarzenia mają `reminders.useDefault: true`, a obie osoby ustawiają domyślne powiadomienia kalendarza „Dom” (10 min przed; całodniowe o 9:00 w dniu). Przypomnienia ustawione w samym wydarzeniu działają tylko u jego twórcy.
4. Dostęp do Kalendarza: klient OAuth (Desktop) + refresh token w `.env`, odświeżany w kodzie, bo węzeł Code nie korzysta z poświadczeń n8n. Zakresy `calendar.events` i `calendar.readonly`; aplikacja w stanie „In production”.
5. `DOM_MODE=test|prod` wybiera kalendarz „Dom-TEST” albo „Dom” (domyślnie `test`).
6. Gdy Gemini dwa razy zwróci niepoprawną odpowiedź, bot pyta przyciskami `📥 Zapisz do posortowania` / `✍️ Napiszę jeszcze raz`.
